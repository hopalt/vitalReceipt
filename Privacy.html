01

개요 및 적용 범위

혈압 가계부(이하 "앱")은 hopalt(이하 "개발사")이 개발한 개인 건강 기록 애플리케이션입니다. 본 방침은 앱 사용 중 수집되거나 처리되는 정보에 대한 내용을 안내합니다.

본 앱은 완전 오프라인 방식으로 작동하며, 사용자의 건강 데이터는 사용자의 기기 내에만 저장됩니다. 개발사는 사용자의 건강 데이터에 접근하거나 이를 수집하지 않습니다.

본 앱은 의료기기가 아닙니다. 앱에 기록된 건강 수치는 개인 참고용이며, 의학적 진단·치료·처방의 근거로 사용할 수 없습니다. 건강 이상 시 반드시 의료 전문가와 상담하세요.

02

수집하는 정보

2-1. 앱이 기기 내에 저장하는 정보 (외부 전송 없음)

아래 정보는 사용자가 직접 입력하거나 앱 기능 사용 중 생성되며, 기기 내 로컬 데이터베이스(SQLite)에만 저장됩니다.

정보 유형 수집 내용 저장 위치
건강 수치 체중(kg), 최고혈압, 최저혈압, 심박수, 측정 시각 기기 내 DB
혈당 (선택) 혈당 수치(mg/dL), 측정 타이밍, 메모 기기 내 DB
복용약 정보 약 이름, 복용 시간, 복용 요일, 메모, 약 사진(선택) 기기 내 저장소
복용 기록 복용 완료·건너뜀·미복용 상태 및 시각 기기 내 DB
식단 영수증 촬영 사진 + 수치 합성 이미지 → 갤러리에만 저장, 앱 내 미보관 기기 갤러리

2-2. 앱이 수집하지 않는 정보

  • 이름, 생년월일, 성별, 전화번호, 이메일 등 개인 식별 정보
  • 위치 정보(GPS)
  • 연락처, 문자, 통화 기록
  • 기기 고유 식별자(IMEI 등)
  • 로그인 정보(회원가입 없음)
03

광고 및 제3자 SDK

본 앱은 무료 서비스 유지를 위해 Google AdMob 광고 SDK를 포함합니다. 개발사의 건강 데이터 처리와는 완전히 독립적으로 작동합니다.

📢 Google AdMob 광고 SDK

수집 주체: Google LLC (개발사 아님)

수집 가능 정보: 광고 식별자(GAID/IDFA), 광고 상호작용, 기기 정보(OS 버전·화면 크기 등), 대략적 위치(IP 기반)

수집 목적: 맞춤형 광고 표시, 광고 효과 측정

보관: Google 서버 (개발사 접근 불가)

Google 개인정보처리방침: https://policies.google.com/privacy

Android: 설정 → Google → 광고 → '광고 개인 최적화 선택 해제'로 맞춤 광고를 끌 수 있습니다.
iOS: 설정 → 개인 정보 보호 → 추적 → 앱의 추적 요청 허용 해제

05

데이터 보관 및 삭제

보관 기간

사용자가 직접 삭제하거나 앱을 삭제할 때까지 기기 내에 보관됩니다. 개발사는 보관 기간을 결정하거나 데이터에 접근할 수 없습니다.

삭제 방법

  • 개별 기록 삭제: 기록 화면에서 항목 삭제
  • 전체 데이터 삭제: 설정 → 전체 데이터 삭제
  • 앱 삭제: 기기에서 앱을 삭제하면 로컬 DB의 모든 데이터가 완전 삭제됩니다

데이터 내보내기 / 이전

설정 → 데이터 내보내기를 통해 JSON 형식으로 즉시 추출할 수 있습니다. 기기 변경 시 JSON 파일을 이용해 새 기기에서 복원하세요.

06

아동 개인정보 보호

본 앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 아동이 앱을 사용하는 경우, 보호자의 지도 아래 사용할 것을 권고합니다.

개발사는 아동으로부터 의도적으로 개인정보를 수집하지 않으며, 아동의 개인정보가 수집된 사실을 인지한 경우 즉시 삭제 조치합니다.

07

보안

사용자의 건강 데이터는 외부로 전송되지 않으므로 네트워크 상의 데이터 유출 위험이 없습니다. 기기 자체의 보안(화면 잠금, 암호화 등)을 통해 데이터를 보호하세요.

기기 분실·도난 시, 기기 잠금 해제 없이는 앱 데이터에 접근할 수 없습니다(기기 보안 설정에 따라 다를 수 있음).
