💓

혈압·심박 초고속 입력

화면 가득 채운 전용 숫자 키패드로 최고혈압→최저혈압→심박수를 탭 이동 없이 한 호흡에 입력합니다.

🧾

감성 영수증 렌더링

식단 사진에 오늘의 체중·혈압·심박 데이터를 도트 폰트로 입혀 영수증 한 장으로 갤러리에 저장합니다.

⚖️

체중 기록

전용 숫자 키패드로 체중을 빠르게 입력합니다. 최근 기록 추이를 한눈에 확인할 수 있어요.

💊

복용약 스마트 알림

식단 촬영 후 N분 뒤 자동 알림, 또는 지정 시각 알림. 복용 완료·건너뜀 기록으로 복용률도 확인하세요.

📊

복용 통계

요일별·약별 복용률을 한눈에. 연속 복용일 기록으로 꾸준한 복용 습관을 만들어보세요.

📤

JSON 데이터 내보내기

모든 수치 데이터를 초경량 JSON으로 즉시 추출. PC로 옮겨 엑셀로 자유롭게 분석하세요.

HOW IT WORKS

하루 세 번의 루틴

아침에 재고, 측정하고, 찍으면 끝. 그게 전부입니다.

01

체중·혈압 입력

앱을 열고 숫자 키패드로 체중과 혈압·심박수를 타다닥 입력합니다. 탭 이동도 없이 10초면 완료.

02

식단 촬영

밥 먹을 때 앱 내 카메라로 찍으면 오늘의 수치가 자동으로 입혀진 영수증 이미지가 갤러리에 저장됩니다.

03

약 알림 수신

식단 촬영 후 설정한 시간이 지나면 복용약 알림이 울립니다. 앱에서 복용 완료를 확인하세요.
